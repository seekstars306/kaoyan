# 考研上岸 · 学习平台（2028 考研）

纯本地、离线可用的考研学习平台，覆盖 **英语二 / 数学二（含数一扩展） / 408**，共 **204 个知识点、480 道随堂测验题、126 词词库**。

## 使用方法

**双击 `index.html` 即可使用**（推荐 Chrome / Edge 浏览器）。无需安装、无需联网（AI 功能除外）。

- 所有数据（学习进度、错题、背词记录、计划勾选、AI 配置）保存在本机浏览器 localStorage，换浏览器/清缓存会丢，请勿使用无痕模式。

## 账号体系

平台已启用**登录门禁**：打开任何页面都需要先登录，学习数据按账号相互隔离。

- **内置管理员**：账号 `admin`，初始密码 `kaoyan2028`（首次登录后请在「设置 → 账号」中修改；修改前登录页会显示初始密码提示）
- **注册**：入口已在登录页就位，但**默认关闭**（显示"注册暂未开放"）。管理员可在「设置 → 用户管理」中勾选"开放注册入口"临时开放，或直接在用户管理中**创建账号 / 重置密码 / 删除用户**
- **会话**：默认 30 天免登录（可取消勾选），退出登录在「设置 → 账号」或手机端「我的」页
- 密码加盐 SHA-256 哈希存储，明文不落盘

> 诚实说明：这是纯本地应用，登录用于多人共用一台设备时隔离数据与防止误操作，不是服务端级安全边界。

## AI 辅助学习（可选，免费功能不受影响）

平台内置 AI 学习助手，需要在「设置 → AI 服务」配置后解锁：

- **问 AI**：任意知识点页右下角「问 AI」，自动携带本节内容上下文答疑
- **单词助手**：任意单词生成 词根拆解 + 联想记忆 + 考研例句 + 近义辨析
- **句子分析**：按课程「长难句拆解五步法」逐层解析任意英文句子
- **造句批改**：用当日所学单词造句，AI 纠错并给升级版
- **翻译批改**：模块 6 第 3 节内置真题演练 + 一键批改
- **作文批改**：模块 7 第 4 节粘贴作文，按考研评分维度批改

**服务商预设**（设置页一键填入）：

| 预设 | 说明 |
|---|---|
| 智谱 GLM（推荐学生党） | open.bigmodel.cn 注册，glm-4-flash 有免费模型 |
| DeepSeek | platform.deepseek.com，价格极低 |
| 本地 Ollama | 完全免费离线；以 `OLLAMA_ORIGINS=* ollama serve` 启动 |

API Key 只保存在本机浏览器。若某服务商拒绝本地文件（file://）来源导致跨域失败，可用本地静态服务打开本平台：

```bash
cd 本平台目录 && python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 线上部署

平台已部署到服务器：**http://43.226.46.67:8001**（手机/电脑浏览器直接访问，账号体系与数据按浏览器 origin 隔离——线上与本地 file:// 的数据互不相通）。

服务器端（Ubuntu 20.04）：
- 站点目录：`/opt/kaoyan`（纯静态，**nginx 承载**：SPA 回退、gzip、KaTeX 字体 30 天不可变缓存、woff2 MIME）
- 服务：`systemd` 单元 `kaoyan.service`（开机自启、崩溃自动拉起）
- 常用运维命令（SSH 到服务器后）：
  - 查看状态：`systemctl status kaoyan`
  - nginx 重载：`nginx -t && systemctl reload nginx`（旧 python 服务 kaoyan.service 已停用，回滚用 `systemctl enable --now kaoyan`）
  - 更新内容：本地重新打包上传解压到 /opt/kaoyan 后 `systemctl restart kaoyan`

⚠️ 公网部署安全提示：首次登录后**立即修改管理员初始密码**；如需更私密，可在服务器用 nginx 反代加 Basic Auth 或 HTTPS。

## 手机上使用

平台会**自动判断设备**（屏幕宽度 + 浏览器 UA）：手机打开时自动切换为移动版式——

- 底部标签栏：**首页 / 数学 / 英语 / 408 / 我的**（我的页聚合 背单词、错题本、学习计划、设置）
- 顶栏收起，卡片单列排布，超宽公式与表格支持**横向滑动**
- 适配 iPhone 刘海屏安全区

各端进度都存在各自浏览器的 localStorage 中（手机与电脑数据不互通）。

| 手机 | 打开方式 |
|---|---|
| Android | 用 Chrome 打开本目录的 index.html（文件管理器 → 选择"浏览器"打开） |
| iPhone | iOS 不支持 file:// 运行网页，建议：电脑上 `python3 -m http.server 8080`，手机连同一 Wi-Fi 访问 `http://电脑IP:8080`；或使用支持本地网页的 App（如 Koder + 浏览器） |

> 提示：AI 功能在手机浏览器同样可用（配置好服务商后）。

## 学习建议（零基础路线）

1. 先读「学习计划」页的三阶段总览，确认目标院校初试科目（多数院校还要考政治！）
2. 数学从「预备篇第 0 章」开始，英语从「模块 0 从字母到句子」开始，408 从「数据结构 C 语言预备」开始
3. 每天固定：背单词 15-20 分钟（清空今日队列）→ 主攻 1-2 个新知识点 → 做完随堂测验
4. 每周日花 30 分钟过一遍本周错题本，比多学一章更值钱
